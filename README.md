# Brawlers

Server emulator project for BrawlBusters (for my friend.)

Funny enough, my friend simply asked me how long it would take me, so I asked him to send me the game files and I would have a look!


Multiple client improvements were made as well such as:
* FOV Changer
* FPS Unlock (Originally limited to 90 FPS)
